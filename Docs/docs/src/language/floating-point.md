# Floating-Point Numbers

Floating-point values use:

```forge
Number Float
```

Example:

```forge
Number Float Temperature = 21.5;
```

Floating-point arithmetic supports the standard arithmetic operators:

```forge
Number Float A = 10.5;
Number Float B = 2.0;

Number Float Result = A + B;
```

A floating-point value can be read from standard input using `Input(Float)`:

```forge
Number Float Value = Input(Float);
```

See [Input](input.md) and [Operators](operators.md) for more details.

# Operators Reference

This is a compact reference for the operators described in the language chapters.

## Arithmetic

| Operator | Meaning |
| -------- | ------- |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `**` | Exponentiation |

## Comparison

| Operator | Meaning |
| -------- | ------- |
| `<` | Less than |
| `>` | Greater than |
| `<=` | Less than or equal |
| `>=` | Greater than or equal |
| `==` | Equal |
| `!=` | Not equal |

## Logical / Bitwise

| Operator | Meaning |
| -------- | ------- |
| `And` | Bitwise AND |
| `Or` | Bitwise OR |
| `Xor` | Bitwise XOR |

## Unary

| Operator | Meaning |
| -------- | ------- |
| `-` | Negation |
| `+` | Unary plus, a no-op |
| `++` | Postfix increment |
| `--` | Postfix decrement |

See [Operators](../language/operators.md), [Unary Operators](../language/unary.md), [Comparisons](../language/comparisons.md), and [Logical Operators](../language/logical.md) for the full discussion and caveats.

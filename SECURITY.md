# Security Policy

## Supported Versions

ForgeLang is currently under active development and is not yet considered stable.

| Version              | Supported          |
| -------------------- | ------------------ |
| Latest release       | :white_check_mark: |
| Older releases       | :x:                |
| Development versions | :x:                |

Security fixes will generally target the latest release.

## Reporting a Vulnerability

If you discover a security vulnerability in ForgeLang, please **do not publicly disclose it in a GitHub issue**.

Instead, report it privately through the security reporting options provided by the ForgeLang GitHub repository.

When reporting a vulnerability, please include:

* A description of the vulnerability
* Steps to reproduce it
* A minimal example, if applicable
* The affected ForgeLang version
* Any relevant compiler output or other technical details

Please allow the maintainers reasonable time to investigate and address the issue before publicly disclosing the vulnerability.

## Scope

Security reports may include vulnerabilities in:

* The ForgeLang compiler
* The ForgeLang runtime or standard library, where applicable
* Official ForgeLang tooling

General bugs, feature requests, or compiler crashes that do not present a security risk should be reported through the normal GitHub issue tracker.

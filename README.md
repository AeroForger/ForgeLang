# ForgeLang-Pre-Alpha

Current version -> Pre-Alpha 2.3

Currently written in Lua

## Progress

it can do:

```ForgeLang
Number X = 1;
Number Y = 2;
Weld String = "I'm a string type";
Print("Hello");
Print(String);
Print(X + Y);
```
out put will be:

```ForgeLang
Hello
I'm a string type
3
```

## Furnace - Compiler/interpreter

First working version has only the interpreter but im planning to add a Compiler feature too it

### How it works:
it requires a Furnace folder in the operating system with the interpreter files and bash commands

### Using it:

first you have to added it to your shell (bash/fish/zsh) and then run

```

Furnace name.anvil

```
